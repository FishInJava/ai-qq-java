任务：$ARGUMENTS

1. 需要用到某个原则时，用 skill 工具按 id 加载对应的 `principle-*` skill 全文再动手，不要凭记忆复述原则内容。
2. 回复里说明本次用到了哪些原则，以及它们具体改变了什么做法。
3. 面向用户的文字（回复、报告、日志、前端文案）按 `unslop` skill 的要求写。
4. 任务缺少必要信息时先问，不要猜。
